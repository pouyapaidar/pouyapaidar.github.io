Research

Most of my work sits where deep learning meets medicine, plus the engineering it takes to run models reliably at scale.

Medical image analysis

Deep learning and image processing for breast cancer detection and for detecting dental anomalies.

Object detection on small datasets

YOLO models for detection and classification, and how data augmentation changes the results when labelled data is scarce.

Drug discovery and repurposing

Machine-learning methods that rank how well drugs work and help find new uses for existing ones.

Distributed AutoMLOps

Automating the machine-learning lifecycle, from data preparation and model search to training, deployment and monitoring, across distributed computing resources.

Natural language processing

Language models and text analysis.

Applied machine learning

Blockchain for renewable-energy systems, and data analysis for digital marketing.
