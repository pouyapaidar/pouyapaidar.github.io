Research

Most of my work sits where deep learning meets medicine. My current work comes first, followed by wider research interests.

Medical image analysis

Deep learning and image processing for breast cancer detection and for detecting dental anomalies.

Object detection on small datasets

YOLO models for detection and classification, and how data augmentation changes the results when labelled data is scarce.

Drug discovery and repurposing

Machine-learning methods that rank how well drugs work and help find new uses for existing ones.
